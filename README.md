# Components that refuse to be cached in CacheView

This repository contains sample applications used to validate ASP.NET Core Issue #69125 - Components that refuse to be cached in CacheView and evidence.

## Contents
- Static SSR sample application
- Validation report and test results
- Video evidences

## Deployment / Running the Samples

```bash
cd CacheViewValidationSSR
dotnet restore
dotnet build
dotnet run
```
